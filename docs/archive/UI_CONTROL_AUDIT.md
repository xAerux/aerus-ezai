The scanner does not read model contents or credentials.
- A real Windows scan completed against the owner machine with local registry, process, PATH, shortcut, and runtime evidence. Exact discovered app/model names, versions, and local paths are kept out of this audit and the Git checkpoint.
- Absence from supported search sources is reported as `Not Detected`, with evidence explaining that unsearched locations are not ruled out; failed scan coverage uses `Scan Incomplete`, and shortcut-only findings use `Needs Verification`. `Data Found Only` is distinct from application or runtime installation. Credentials, private content, and subscription state are not queried.
- Ollama endpoint/version and model data are verified against independent local `/api/tags`, `/api/show`, PATH, registry, and process evidence. No model blob was opened or hashed. The UI/API tests do not demonstrate installer or launch functionality; those actions are intentionally out of scope.
- Hardware API tests passed. Discovery API tests passed response shape, separate Codex identities, unique model identities, same-origin denial, custom folder model/CLI detection, and retry. TypeScript and production build passed. The UI suite passed scan retry, real result persistence, four-tab navigation, card and Learn behavior, prompt template/copy/save/reload, consistent coding-agent status across Home and AI Installers, and no horizontal overflow at 1366×768, 1920×1080, 2560×1440, and 3440×1440.
- Launcher restart, cached hardware/software inventory, and saved-prompt persistence passed in `tests/VerifyHardwareUi.mjs postrestart`.
- Exact custom application locations outside known folders are detected only when explicitly added in My Models. This is an owner-approved opt-in scan path and remains bounded; no drive-wide search is performed.
- LM Studio's CLI branch is conditional on a recognized `lms` executable; the owner system did not expose `lms` on the scan PATH and no LM Studio installation was found, so that live branch remains unverified here. Mission 04R verified Comfy Desktop 1.1.7 from its installed-program registration and valid shortcut target, verified its managed ComfyUI runtime manifest and `main.py`, confirmed the default local health endpoint during the scan, and inventoried 39 actual model files from `ComfyUI-Shared\models`.
