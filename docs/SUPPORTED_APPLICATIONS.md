# Supported AI Applications and Integrations

EZ AI identifies products using the best available Windows registration, verified shortcut/executable evidence, known CLI installation evidence, or local runtime response. A result is not an account, subscription, license, or sign-in check. Availability and exact launch support depend on the installed product version.

| Product family | EZ AI support | Important distinction |
|---|---|---|
| ChatGPT / Codex Desktop | Detect and activate supported registered Windows app | Current unified desktop package may include Codex; it is separate from Codex CLI. A web login or open browser tab is not desktop installation evidence. |
| Codex CLI | Detect; approved interactive project terminal when identity/workspace checks pass | CLI is not ChatGPT Desktop. No prompt is submitted by launch. |
| Claude Desktop | Detect and launch only with verified Windows application evidence | Separate from Claude Code and does not prove a paid plan. |
| Claude Code | Detect; approved interactive terminal for a selected project | Separate CLI product; provider/account configuration belongs to Anthropic. |
| Gemini | Identify official web app; Windows desktop installation is not assumed | Browser/PWA availability is distinct from a verified native app. |
| Gemini CLI | Detect supported CLI evidence | Installation/launch depends on verified local CLI and interactive user approval. |
| Grok / Grok Desktop | Keep official web app and third-party Windows wrappers as distinct identities | A wrapper does not prove xAI publisher identity or a Grok plan. |
| Cursor | Detect and launch supported verified Windows installation | Cursor plan limits are separate from API/provider charges. |
| Ollama Desktop / local runtime / CLI | Detect Desktop, server health, CLI and model inventory separately; user-triggered Open where safe | A running API is not proof the Desktop GUI is installed or running. No scan downloads models. |
| LM Studio | Detect app/local server and recognized model inventory where supported | API/model-management features vary by LM Studio version. |
| ComfyUI Desktop / local backend | Detect Desktop, local backend, model assets and workflow readiness separately | Matching files alone do not prove a workflow is ready. EZ AI does not modify workflows, nodes, environments or model files during scanning. |
| OpenCode | Detect CLI and launch approved interactive terminal when prerequisites pass | OpenCode is an independent agent that can use Ollama; it is not part of Ollama. |
| StarNet | Detect and launch only from verified signed Windows identity | Connected model providers and account terms are separate. |

Installation actions are contextual and require explicit approval. This table does not promise that every product has a direct EZ AI installer; official setup guidance or verification may be the only supported action.

## Optional integrations

The Codex Usage Monitor remains a separate, optional companion and is not bundled. EZ AI does not read usage history or credentials. Ollama agent launch routes and local coding agent features require separately installed tools and user approval. No optional integration is needed to open EZ AI or read bundled Knowledge content.
