# Reporting an EZ AI Issue

The public issue tracker and distribution channel have not been established. Do not upload logs, screenshots, profile exports, model paths, project names, usage history, credentials or private prompts to a public site.

When an owner-approved support channel is available, include:

- EZ AI version shown in Settings.
- Windows edition and architecture.
- The feature and the action you took.
- The exact non-sensitive error text.
- Whether the issue repeats after a normal restart.
- A minimal reproduction using a disposable project/profile when possible.

Review diagnostic files and screenshots for personal paths and local hardware/model details before sharing. Never include API keys, tokens, account identifiers, private conversations, or full app-data exports.
