Codex Efficiency Setup

The Codex twin of the Claude setup. One PowerShell script checks what you have, then asks before it installs tools or writes Codex settings and working rules. Optional agent files are available but off by default.

01 Run it

Download the script, read what it does, then run it. Every change is shown and asked for first. The only manual step is the sign-in, which is a browser login that no script does for you.

Before you run it: what can change

  • Software (only if you approve): Node.js LTS and Git through winget, if they are missing; the Codex CLI (@openai/codex) and ccusage through npm, if they are missing. Each is installed globally by its own package manager.
  • Codex files (only if you approve): config.toml is created only when none exists. If one exists, it is never modified; the suggested settings go to aeru-efficiency-snippet.toml. AGENTS.md gets a marked rules block appended after a timestamped backup, and is not changed again once the block is present.
  • Optional agent files (off by default): agents/scout.toml and agents/reviewer.toml, only if they do not already exist.
  • Nothing else: no global instructions, system settings, or other config files are touched. Your Codex home is the CODEX_HOME folder if set, otherwise %USERPROFILE%\.codex.

Prompts do not guarantee results, and Codex usage and cost depend on your OpenAI plan or API billing.

02 What the script does

The script first lists the current state and changes nothing. Then it asks, step by step, before anything is installed or written.

A Install tools (asks first)

Installs any missing Node.js LTS and Git through winget, then the Codex CLI and ccusage through npm. If winget is not present, the script says so and installs nothing. Answering No skips this step entirely.

B Settings and rules (asks first)

Creates config.toml only if none exists. Creates or extends AGENTS.md with the working-rules block, backing up the existing file first. Re-running the script does not add the block twice.

C Optional subagents (asks first, off by default)

Writes scout.toml and reviewer.toml into agents/ under your Codex home, only if those files are missing. Check the Codex subagent documentation for your version to confirm they load; the script does not depend on them.

+ Result

Each step reports ok, warn or fail. Approved steps that succeed stay done even if a later step fails.

— The config safety rule

Already have a config.toml? The script does not modify it.

The suggested settings are written to aeru-efficiency-snippet.toml in the same folder. Merge them yourself if you want them. The script never writes a model name, so no model is pinned unless you add one.

03 Optional subagents

Off by default. Skip this section unless you want the two extra agent files and have checked that your Codex version loads them.

scout optional

Intended for bounded search and exploration. Each file has a name, a description, and developer_instructions, as Codex's custom-agent format requires. No model is set, so it uses your default model.

file    <CODEX_HOME>/agents/scout.toml
reviewer optional

Intended for second opinions on a diff or design. Same format as scout, with no model set.

file    <CODEX_HOME>/agents/reviewer.toml

Verify before you rely on them

Run Codex and ask it to list its available agents. If the files do not appear, they are not loaded in your version, and you can delete them without affecting anything else.

05 The script

The whole thing, readable before you run it — that's the point of shipping it as a file instead of a one-liner. Download it or copy it straight into a .ps1.

setup-codex-efficiency.ps1 
<#
================================================================================
  AERU - CODEX EFFICIENCY SETUP (Windows, PowerShell 5.1 or 7)

  This script is OPTIONAL. It makes no changes until you approve each step.

  STEP A - Install tools (only if you approve):
    - Node.js LTS and Git, through winget, if they are missing
    - Codex CLI (npm package @openai/codex) and ccusage (npm package ccusage)

  STEP B - Change Codex files (only if you approve):
    - config.toml: written only when none exists. If you already have one,
      the suggested settings go to aeru-efficiency-snippet.toml instead, and
      your config.toml is not modified.
    - AGENTS.md: a marked block of working rules is appended. If the block is
      already present it is not added again. Existing files are backed up first.

  STEP C - Optional subagents (off by default):
    - agents\scout.toml and agents\reviewer.toml, only if they do not exist.
      Read the Codex subagent documentation to confirm they load in your version.

  Your Codex home is the CODEX_HOME folder if that variable is set, otherwise
  %USERPROFILE%\.codex.
================================================================================
#>

$ErrorActionPreference = 'Continue'
$problems = 0

function Ok($text)   { Write-Host "  [ok]   $text" -ForegroundColor Green }
function Warn($text) { Write-Host "  [warn] $text" -ForegroundColor Yellow }
function Fail($text) { $script:problems++; Write-Host "  [fail] $text" -ForegroundColor Red }
function Step($text) { Write-Host ""; Write-Host "== $text" -ForegroundColor Cyan }
function Have($name) { return [bool](Get-Command $name -ErrorAction SilentlyContinue) }
function Refresh-Path {
    $env:Path = [System.Environment]::GetEnvironmentVariable("Path", "Machine") + ";" + [System.Environment]::GetEnvironmentVariable("Path", "User")
}
function Ask-YesNo($question) {
    $answer = Read-Host "$question [y/N]"
    return ($answer -match '^(y|yes)$')
}
function Write-Utf8NoBom($path, $text) {
    [IO.File]::WriteAllText($path, $text, (New-Object System.Text.UTF8Encoding($false)))
}
function Append-Utf8NoBom($path, $text) {
    [IO.File]::AppendAllText($path, $text, (New-Object System.Text.UTF8Encoding($false)))
}
function Backup-File($path) {
    $stamp = Get-Date -Format 'yyyyMMdd-HHmmss'
    $backup = "$path.bak-$stamp"
    Copy-Item -LiteralPath $path -Destination $backup -Force
    return $backup
}

# ---- Where Codex lives on this computer -----------------------------------
if ($env:CODEX_HOME -and $env:CODEX_HOME.Trim() -ne '') { $codexHome = $env:CODEX_HOME.Trim() } else { $codexHome = Join-Path $HOME '.codex' }
$configPath   = Join-Path $codexHome 'config.toml'
$snippetPath  = Join-Path $codexHome 'aeru-efficiency-snippet.toml'
$agentsMdPath = Join-Path $codexHome 'AGENTS.md'
$agentsDir    = Join-Path $codexHome 'agents'
$marker = '<!-- AERU-EFFICIENCY-RULES v1 -->'

Write-Host ""
Write-Host "Codex efficiency setup" -ForegroundColor Cyan
Write-Host "Codex home: $codexHome"
Write-Host ""
Write-Host "Current state (nothing has been changed yet):"
Write-Host ("  node        : " + $(if (Have 'node') { 'installed' } else { 'missing' }))
Write-Host ("  git         : " + $(if (Have 'git') { 'installed' } else { 'missing' }))
Write-Host ("  npm         : " + $(if (Have 'npm') { 'installed' } else { 'missing' }))
Write-Host ("  codex       : " + $(if (Have 'codex') { 'installed' } else { 'missing' }))
Write-Host ("  ccusage     : " + $(if (Have 'ccusage') { 'installed' } else { 'missing' }))
if (Test-Path -LiteralPath $configPath) { Write-Host "  config.toml : exists - will NOT be modified" } else { Write-Host "  config.toml : missing - will be created" }
if (Test-Path -LiteralPath $agentsMdPath) {
    $existingAgents = Get-Content -LiteralPath $agentsMdPath -Raw
    if ($existingAgents -and $existingAgents.Contains($marker)) { Write-Host "  AGENTS.md   : rules block already present - skipped" }
    else { Write-Host "  AGENTS.md   : exists - a rules block will be appended after a backup" }
} else { Write-Host "  AGENTS.md   : missing - will be created" }
Write-Host ""

# ---- Step A: tools ---------------------------------------------------------
Step 'Step A - Install tools (optional)'
if (Ask-YesNo 'Install any missing tools now (winget and npm will run)?') {
    if (-not (Have 'winget')) {
        Warn "winget was not found. Install 'App Installer' from the Microsoft Store, then run this script again."
    } else {
        if (-not (Have 'node')) {
            Write-Host '  Installing Node.js LTS with winget...'
            & winget install --id OpenJS.NodeJS.LTS -e --accept-source-agreements --accept-package-agreements
            if ($LASTEXITCODE -eq 0) { Ok 'Node.js installed' } else { Fail "winget could not install Node.js (exit $LASTEXITCODE)" }
        }
        if (-not (Have 'git')) {
            Write-Host '  Installing Git with winget...'
            & winget install --id Git.Git -e --accept-source-agreements --accept-package-agreements
            if ($LASTEXITCODE -eq 0) { Ok 'Git installed' } else { Fail "winget could not install Git (exit $LASTEXITCODE)" }
        }
    }
    Refresh-Path
    if (-not (Have 'npm')) {
        Fail 'npm is not available. Close and reopen PowerShell, then run this script again.'
    } else {
        if (-not (Have 'codex')) {
            Write-Host '  Installing the Codex CLI (npm package @openai/codex)...'
            & npm install -g @openai/codex
            if ($LASTEXITCODE -eq 0) { Ok 'Codex CLI installed' } else { Fail "npm could not install @openai/codex (exit $LASTEXITCODE)" }
        }
        if (-not (Have 'ccusage')) {
            Write-Host '  Installing ccusage (npm package ccusage)...'
            & npm install -g ccusage
            if ($LASTEXITCODE -eq 0) { Ok 'ccusage installed' } else { Fail "npm could not install ccusage (exit $LASTEXITCODE)" }
        }
    }
    Refresh-Path
} else {
    Ok 'Skipped. No tools were installed.'
}

# ---- Step B: Codex files ---------------------------------------------------
Step 'Step B - Codex settings and rules (optional)'
if (Ask-YesNo "Write the Codex settings and rules described above to $codexHome ?") {
    try {
        if (-not (Test-Path -LiteralPath $codexHome)) { New-Item -ItemType Directory -Path $codexHome | Out-Null }
    } catch { Fail "Could not create $codexHome : $($_.Exception.Message)" }

    $tunedConfig = @'
# --- AERU efficiency defaults for Codex -------------------------------------
# No model is pinned. Choose a model in Codex or in your own config.
model_reasoning_effort = "medium"
web_search = "cached"
sandbox_mode = "workspace-write"
approval_policy = "on-request"

[features]
multi_agent = true
# --- /AERU efficiency defaults ---------------------------------------------
'@

    try {
        if (Test-Path -LiteralPath $configPath) {
            if (Test-Path -LiteralPath $snippetPath) { $b = Backup-File $snippetPath; Ok "Backed up the old snippet to $(Split-Path $b -Leaf)" }
            Write-Utf8NoBom $snippetPath $tunedConfig
            Ok 'config.toml already exists and was NOT modified.'
            Ok 'Suggested settings saved to aeru-efficiency-snippet.toml. Merge them yourself if you want them.'
        } else {
            Write-Utf8NoBom $configPath $tunedConfig
            Ok 'config.toml created with the efficiency defaults.'
        }
    } catch { Fail "config.toml step failed: $($_.Exception.Message). No other file in this step was changed." }

    $rules = @'

<!-- AERU-EFFICIENCY-RULES v1 -->
## Working rules (token discipline and accuracy)

- Work on the files and symptoms I name. Do not explore the whole repository unless asked.
- Prefer targeted edits. Search before reading large files end to end.
- Never claim something was installed, changed, tested, or published unless it was verified.
- Ask before deleting files, changing configuration, or installing software.
- Keep each task in its own session; start fresh when the task changes.
<!-- /AERU-EFFICIENCY-RULES v1 -->
'@
    try {
        if (Test-Path -LiteralPath $agentsMdPath) {
            $current = Get-Content -LiteralPath $agentsMdPath -Raw
            if ($current -and $current.Contains($marker)) {
                Ok 'AGENTS.md already has the rules block. It was not added again.'
            } else {
                $b = Backup-File $agentsMdPath
                Ok "Backed up AGENTS.md to $(Split-Path $b -Leaf)"
                if ($current -and -not $current.EndsWith("`n")) { Append-Utf8NoBom $agentsMdPath "`r`n" }
                Append-Utf8NoBom $agentsMdPath $rules
                Ok 'Rules block appended to AGENTS.md.'
            }
        } else {
            Write-Utf8NoBom $agentsMdPath ($rules.TrimStart("`r", "`n"))
            Ok 'AGENTS.md created with the rules block.'
        }
    } catch { Fail "AGENTS.md step failed: $($_.Exception.Message). Any backup made is next to the file." }
} else {
    Ok 'Skipped. No Codex files were changed.'
}

# ---- Step C: optional subagents --------------------------------------------
Step 'Step C - Optional subagents (off by default)'
if (Ask-YesNo 'Add the optional scout and reviewer agent files (only files that do not exist yet)?') {
    try {
        if (-not (Test-Path -LiteralPath $agentsDir)) { New-Item -ItemType Directory -Path $agentsDir | Out-Null }
        $scout = @'
name = "scout"
description = "Read-only search, exploration and extraction. Use for finding files and tracing where things are defined or used."
developer_instructions = """
You are a scout. You do read-only exploration and report back; you never edit anything.
Answer exactly what was asked, with file paths and line references.
Return facts and pointers, not file dumps. If you did not find it, say so.
"""
'@
        $reviewer = @'
name = "reviewer"
description = "Second opinion on a diff or design. Use when correctness matters more than speed."
developer_instructions = """
You are a reviewer. You analyze and critique; you never edit anything.
Read the actual code before judging it and cite files and lines.
List the most serious risks first. Label verified problems separately from suspicions.
"""
'@
        foreach ($pair in @(@('scout.toml', $scout), @('reviewer.toml', $reviewer))) {
            $path = Join-Path $agentsDir $pair[0]
            if (Test-Path -LiteralPath $path) { Ok "$($pair[0]) already exists - left untouched" }
            else { Write-Utf8NoBom $path $pair[1]; Ok "$($pair[0]) created" }
        }
    } catch { Fail "Subagent step failed: $($_.Exception.Message)" }
} else {
    Ok 'Skipped. No agent files were written.'
}

# ---- Result ----------------------------------------------------------------
Write-Host ""
if ($problems -eq 0) {
    Write-Host 'Finished. Nothing was changed except the steps you approved above.' -ForegroundColor Green
} else {
    Write-Host "Finished with $problems problem(s). Read the [fail] lines above; approved steps that succeeded are complete." -ForegroundColor Yellow
}
Write-Host 'Next: run codex once and sign in with your ChatGPT account, or use an OpenAI API key.'

After the script and sign-in, open Codex inside your project and paste everything in this file as your first message. Codex finishes the setup and verifies the script's work — run it once per project. Step 2 checks the optional subagents only if you installed them; step 3 reads your global rules back to you.

FIRST-RUN-SETUP-PROMPT-CODEX.md 
# FIRST-RUN SETUP PROMPT — CODEX EDITION

**How to use:** After running `setup-codex-efficiency.ps1` and signing in,
open Codex *inside your project folder* and paste everything between the
lines below as your first message. Codex finishes the setup and verifies the
script's work. Run it once per project.

---

You are my setup agent. Configure this project for token-efficient agentic
coding, then verify the global setup. Work through this list in order and
report each item as done, skipped, or failed (with the actual error):

1. **Merge and validate the global config.** Look for
   `~/.codex/aeru-efficiency-snippet.toml`. If it exists, merge its settings
   into `~/.codex/config.toml`: on any conflict, keep my existing value
   except for `web_search = "cached"` and `multi_agent = true`, which should
   win. Validate the result is legal TOML. If the snippet doesn't exist, my
   config was written directly — validate it the same way. Then confirm the
   effective values of: `model_reasoning_effort`, `web_search`,
   `sandbox_mode`, `approval_policy`, and `features.multi_agent`.

2. **Check the optional subagents.** Only if `~/.codex/agents/scout.toml`
   or `~/.codex/agents/reviewer.toml` exist: confirm each has `name`,
   `description`, and `developer_instructions`, and that it parses as TOML.
   Do not change any model names. If the files are missing, say "skipped" and
   continue. Do not claim a subagent works unless you actually ran it.

3. **Confirm the global rules loaded.** Read `~/.codex/AGENTS.md` and confirm
   the block marked `AERU-EFFICIENCY-RULES` is present. Summarize its rules
   back to me in 3 lines so I know they're active.

4. **Write this project's AGENTS.md.** Scan the repo and write a project
   `AGENTS.md` of AT MOST 100 lines containing only: what this app is (2-3
   lines), the stack, how to build/run/test it (exact commands), the folder
   map (one line per major folder), and any project-specific gotchas you can
   verify from the code. No generic advice — if you can't verify it from
   this repo, leave it out. Show me the file when done.

5. **Measure the baseline.** Run `ccusage codex daily` (or
   `npx ccusage@latest codex daily`) and report: total tokens, estimated
   cost, and cached-token share so far. Note: OpenAI caching is automatic —
   if the cached share is low, tell me the most likely reason from how the
   sessions look.

6. **Final report.** One short list: what you changed, what you verified as
   already correct, and anything that needs my decision. Nothing else.

Rules for you, starting now and for every future session in this project:
- When I give you a photo or screenshot of a UI, build THAT UI exactly — do
  not redesign it. This is the rule you have broken before; don't break it
  again.
- If the scout subagent is installed and loads, route search and exploration
  to it. Otherwise do that work yourself. Warn me before doing anything that
  will push the context toward your model's limit.

---

07 Honest notes

What this setup does not promise

It does not guarantee lower cost, fewer tokens, or better results. It writes settings and rules and gives you a usage meter. Whether any of it helps depends on your work, your plan or API billing, and the models available to you.

After setup: the weekly reality check

One command tells you what Codex actually cost and how much of it was cache:

ccusage codex daily

Once you're running both agents, plain ccusage daily shows Claude and Codex combined — one number for the whole operation.
