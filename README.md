# ⚡ AERUS AI EZ

### 🤖 Local AI. Made Easy.

**Created by Aeru Creations**

**Windows Desktop Application | Official Release: v1.0.0-beta.6**

Welcome to **AERUS AI EZ** — a Windows desktop application built to make discovering, installing, launching, and understanding AI tools easier.

AI technology is evolving fast. There are countless models, coding agents, installers, and utilities to keep track of. AERUS AI EZ brings useful tools and information together in one convenient place.

Whether you're just getting started with AI or already building your own projects, EZ AI is designed to help you spend less time figuring things out and more time creating. 🚀

## ✨ Features

| Feature | Description |
|---|---|
| 🏠 **Home** | Your central dashboard for accessing EZ AI's features and utilities. |
| 🤖 **AI Installers** | Discover supported AI applications and access installation and setup options. |
| 💻 **My Models** | Explore local AI model information and available management tools. |

## 🛠️ Meet the Aerus Tools

### 📊 Aerus AI Usage HUD

Ever wondered how many tokens you've burned through while building something? 😂

The **Aerus AI Usage HUD** brings supported token usage information together in one standalone Windows dashboard.

- 🔵 Codex usage tracking
- 🟠 Claude Code usage tracking
- 🟢 Ollama usage tracking through supported captures
- 📈 Usage charts and session history
- 🧮 Separate provider totals and a combined grand total
- 💰 Estimated API-equivalent costs where sufficient data exists

Token tracking depends on the records available from each provider. Some account-only usage cannot be assigned to individual sessions, models, or dates.

### 💾 Aerus SDM

**Aerus SDM** is a Windows utility focused on system visibility, startup management, and diagnostics.

Explore detected startup entries, inspect available system information, and manage supported startup settings from a dedicated desktop interface.

### 🧠 Aerus Codex Crunch

A practical guide for users getting started with Codex and improving their development workflows.

Includes setup information, copyable prompts, and downloadable resources designed to help users organize their coding environment.

### ⚡ Aerus Claude Crunch

Guides and resources for working with Claude Code, including development workflows and available copyable setup content.

Both Crunch tools are intended to help users learn and configure supported features. They do not guarantee better model performance or error-free code.

## 📦 Download & Installation

**Latest official release: v1.0.0-beta.6**

**Installer:** `EZ-AI-Setup-v1.0.0-beta.6.exe`

1. Obtain the official installer from Aeru Creations.
2. Launch the installer on a compatible Windows PC.
3. Follow the installation instructions.
4. Open **AERUS AI EZ** using your Desktop or Start Menu shortcut.
5. Explore your AI tools! 🚀

The installer includes the EZ AI desktop application, Aerus AI Usage HUD, and Aerus SDM.

**⚠️ Windows Security Notice**

AERUS AI EZ is independently developed and currently distributed without a code-signing certificate. Windows may show an unknown-publisher or SmartScreen warning.

Only run installers obtained from a source you trust. Never disable Windows security protections to install the application.

---

## 🔐 Privacy & Local Operation

AERUS AI EZ is built around a local Windows desktop experience.

- Personal token histories and account records are not included in the distributed installer.
- Supported usage information is stored locally by the accompanying HUD.
- Some features require external AI software, accounts, downloads, or internet access.
- Optional setup scripts should always be reviewed before execution.
- Usage estimates are informational and may not reflect actual subscription charges.

The application is not intended to collect every token used across every AI service.
